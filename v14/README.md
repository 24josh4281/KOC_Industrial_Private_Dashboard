# 산업부문 외부사업 대시보드 v14

관리 Tool Excel 2종과 ORS 7월·9월 ZIP 2종을 대조한 판본입니다. 실제 사업명, 신청자, 담당자, 업무 메모와 원본 자료가 포함됩니다. 이 저장소가 공개되면 링크를 아는 사람뿐 아니라 누구나 열람·복제할 수 있습니다.

## 바로 열기

- [① 통계 대시보드](통계_대시보드_v14.html): 관리 Tool의 연도·월별 원장행과 ORS의 최신 원본행, 2026년 접수 근거·현재 상태를 출처별로 비교합니다.
- [② 진행현황 대시보드](진행현황_대시보드_v14.html): ORS 모든 수신 출현행을 범위·수신본·유형·올해 접수/처리 이력·검색어로 조회하고, 현재 상태·월별 접수 그래프, 상세 이력과 CSV를 제공합니다. 관리 Tool 2026 업무 원장은 별도 표입니다.
- [Excel 작업본](외부사업_통합관리_v14.xlsx): 위 두 화면에 대응하는 `통계 대시보드`, `진행현황 대시보드`와 `ORS 전체 진행`, `ORS 2026 인입`, `집계 근거` 시트를 추가했습니다. v13의 원본·입력 시트도 보존합니다.

GitHub의 HTML 파일 미리보기는 대시보드를 실행하지 않습니다. 저장소 ZIP을 내려받아 압축을 푼 뒤 HTML을 열면 화면 간 이동과 Excel·v13 원본 조회 링크가 함께 작동합니다.

## 수치의 의미

7월·9월 ORS ZIP에 XLS 파일 출현 20개, 업무행 출현 5,998개가 있습니다. 유형·범위별 최신 파일은 4,197행이며 그중 산업부문은 2,895행입니다. 산업부문 최신 ORS에서 **2026년 접수 근거가 있는 행은 27개**, **2026년 이력 또는 원본 신청일·처리일이 있는 행은 169개**입니다. 후자의 보완·재제출·처리 이력은 신규 접수로 세지 않았습니다. 전체 범위의 2026 접수 근거는 133행입니다.

관리 Tool의 신청일이 2026년인 원장행 53개는 ORS와 별도로 표시합니다. 두 원장의 동일 사업·신청 회차 여부는 확정 연결하지 않았으므로 수치를 더해 고유 신청 건수로 보고하지 마세요. 원본 신청일이 없거나 이력 표현이 규칙에 맞지 않는 행은 2026 접수 근거에서 빠질 수 있으므로 `ORS 전체 진행`에서 원문을 조회하세요. 이 분류는 법정·계약 기한 판정이 아닙니다.

## 매월 ORS ZIP 반영

1. 새 원본 ZIP을 `v13/incoming/YYYY-MM/`에 보관합니다. v13의 [월별 반영 절차](../v13/README.md)에 따라 미리보기 후 `월별_ORS_확정반영.cmd`로 DB에 반영합니다. ZIP 해시가 같으면 중복 등록하지 않고, 열 구조가 바뀌거나 과거 기준일인 자료는 자동 최신으로 승격하지 않습니다.
2. 이 폴더의 `월별_대시보드_v14.cmd`를 실행합니다. v13 운영 DB를 읽어 `v13/snapshots/기준일_해시/`와 `v14/snapshots/기준일_해시/`에 같은 판본의 출력물을 만듭니다. 파일이 없어도 기준 DB에서 시작합니다.
3. 먼저 `v14/snapshots/.../검증수치_v14.json`의 수신 출현행, 최신행, 2026 접수·처리 이력 수와 새 `ORS 전체 진행` 시트를 확인합니다. 사무국 의견·안내는 v13 `2026 접수·검토·안내`에서 수정하고, CSV 미리보기·확정 반영 후 같은 명령을 다시 실행합니다.

Python 3과 `openpyxl`이 필요합니다. v13 월별 절차의 `requirements-ingest.txt`를 설치하면 됩니다. `build_v14.py --db <DB 경로>`로 직접 실행할 수도 있습니다. 새 ORS 행은 원본 ZIP·파일·시트·행에 연결됩니다. 인입 판정은 명시 신청일, 신규·갱신 신청 접수 이력, 또는 인증 신청의 최초 신청 이력에 한정하며 보완·재제출은 제외합니다.

## 검증과 한계

[검증보고서](검증보고서_v14.md)에 원본 셀·수식 전수 대조와 월별 ZIP 추가 시험 결과가 있습니다. 정적 HTML은 단독 공동편집 도구가 아닙니다. 업무 의견과 사무국 안내는 v13의 CSV→DB 확정 반영을 거쳐 공유 판본에 기록합니다. 향후 관리 Tool의 새 Excel이 들어오면 관리 원장과 ORS 간 동일 신청 연결을 별도 검토해야 합니다.
