최초 공개 판본의 2026년 관리 Tool 신청일 확인 53행, ORS 최신 산업부문 신규 접수 근거 27행, 2026 처리 이력 169행은 **출처가 다른 지표**입니다. 두 원장을 합산해 고유 신청 수로 표시하지 않습니다. 관리 Tool 전체 원장 3,419행과 ORS 수신 원본 5,998행은 각각 추적 가능합니다.

매월 저장소 최상위 `incoming/`에 기존 양식의 ORS ZIP을 업로드해 커밋하면 Actions에서 검증 후 Excel과 웹을 자동 갱신합니다. `incoming/YYYY-MM/` 월별 하위 폴더도 지원합니다. 업무 의견·안내·다음 조치는 최신 Excel의 `2026 접수·검토·안내` 시트를 편집해 `incoming/workflow/current.xlsx`로 올리면 같은 자동 검증 경로로 반영됩니다. 새 판본 배포 후 열린 화면은 30초 간격으로 변경을 감지합니다. 검증 실패 시 기존 공개 판본을 유지합니다. 관리 Tool 원장 기준일은 2026-10-13이며, 최초 공개 판본의 ORS 수신본 기준일은 2026-09-21입니다. 최신 기준일은 화면 상단에 표시됩니다.
