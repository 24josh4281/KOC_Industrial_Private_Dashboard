## 핵심 해석

- 관리 원장 3,419행은 고유 사업 수나 신청 회차 수가 아닙니다. 원본에는 2014년 5행도 있어 보존했습니다. 2015년 이후 보고 시 연도 필터로 분리하세요.
- 전 기간 미종결 표시 535행, 종결 상태 확인 필요 48행을 분리했습니다.
- `30일 초과` 및 `0~30 / 31~90 / 91~365 / 366일 이상`은 **신청 후 경과 달력일에 따른 내부 확인 구간**입니다. 법정·계약 기한 초과, 단계별 체류일 또는 실제 지연 확정이 아닙니다. 신청일이 일자까지 확인되지 않은 미종결 28행은 계산에서 제외했습니다.
- 웹 브리핑의 담당 원문 미확보 165행은 미배정 확정이 아닙니다. 현장방문 원문 기재 256행은 방문 완료 건수가 아닙니다.
- 월별·연도별 집계는 신청일 기준 원장행입니다. 공식 승인연도 실적·신청 회차 실적은 확정된 ID와 승인 사건일이 없어 산출하지 않습니다.
- ORS 추가·미등장은 복합키 매칭 **후보**이며 실제 신규·삭제로 확정하지 않습니다.

## 다음 월 자료 반영

이 파일은 자동 갱신되지 않습니다. 새 ORS 파일을 받으면 원본 범위와 SHA-256, 동일 파일 여부, 신청 회차·키 충돌, 변경 후보를 검수한 뒤 새 판본을 생성해야 합니다. 기존 수기 비고·배정 원문은 덮어쓰지 마세요. 공식 기한 경고는 공단의 규정 판본·업무별 기산일·보완 중단·휴일 규칙이 확인된 뒤 별도로 적용합니다.
