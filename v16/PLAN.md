# v16 PDCA: 회의 요구 대조와 담당자 작업관리

## P · 현황과 판단

회의록의 직접 요구 REQ-01~12를 v15 코드·원본행·Excel과 대조했다. 첨부 기술서의 구현 지시 문장은 제품 기획 자료로만 사용했고, 실제 공개 운영은 이후 사용자의 명시적 공개 요청을 따른다. 수치의 단위는 고유 사업이 아닌 출처별 원본행이며 관리 Tool과 ORS는 확정 연결하지 않는다.

## D · 이번 구현 범위

1. 출처별 2026 작업 대기열: 담당자, 단계, 보완차수, 원본 특이사항, 다음 조치, 입력/자동제안 구분, 마지막 이력일, 내부 30일 점검, 상세 링크.
2. 같은 스냅샷의 Excel에 업무 대시보드·필터 가능한 전체 작업현황·요구사항 점검 시트 추가. 기존 74시트와 원본 셀은 변경하지 않는다.
3. 담당자가 최신 Excel의 `2026 접수·검토·안내` 시트를 편집해 `incoming/workflow/current.xlsx`로 올리면 검증·감사 후 사이트와 Excel에 반영. ORS ZIP과 별도 관리.
4. ORS의 관장기관을 검토기관 또는 최초 검토기관으로 단정하지 않도록 상세 표시 수정.

## C · 필수 검증

- 관리 Tool 53행, ORS 최신 산업 2026 활동 169행이 대기열에 한 번씩 들어갈 것. 출처별 합산은 고유 신청 수로 명명하지 않는다.
- 각 대기열 행의 상세 URL과 Excel 원본/업무입력 위치가 열릴 것.
- 기존 원장 3,419행, ORS 5,998행, 74개 시트의 원본 값과 9개 차트가 유지될 것.
- 수정 Excel 정상 입력·수식/잘못된 키 오류·중복 ZIP 경로를 시험할 것.
- 최종 GitHub Actions와 Pages 게시, 공개 파일 응답을 확인할 것.

## A · 남는 운영 과제

컨소시엄별 제출자료, 공식 기한 규칙, 신청 회차·검토기관 정합성 근거가 확보되면 별도 승인된 매핑을 추가한다. 현재 공개본에는 실제 사업자료가 포함된다.
