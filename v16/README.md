# v16 · 담당자 작업현황

v15의 관리 Tool 3,419행·2026 신청일 53행·ORS 원본 5,998행·2026 산업부문 활동 169행을 유지합니다. v16은 2026 관련 출처별 222행에 담당자 작업현황, 다음 조치의 입력 근거, 특이사항의 출처, 보완차수, 최근 이력 경과일을 붙였습니다. 222는 고유 신청 건수가 아닙니다.

- `statistics.html`: 기존 통계 대시보드.
- `progress.html`: 기존 단계·월별 진행현황 대시보드.
- `work.html`: 담당자 작업 대기열. 우선순위·출처·단계·담당 여부 필터, 검색, CSV, 건별 상세 연결.
- `case.html`: 원본 상세 뒤에 작업현황·다음 단계 추가. ORS 관장기관을 최초/현재 검토기관으로 단정하지 않습니다.
- `외부사업_통합관리_v16.xlsx`: 원본 74개 시트와 차트 9개를 보존하고 업무 운영·담당자 작업현황·회의 요구 점검 3개 시트 및 차트 3개를 추가했습니다.

담당자 입력은 최신 Excel의 `2026 접수·검토·안내` 시트에 기록합니다. 편집 파일을 저장소 `incoming/workflow/current.xlsx`로 업로드하면 53행 연결키·입력값·수식을 검사하고 기존 ORS/관리 원본을 덮어쓰지 않은 채 다시 생성합니다. 수기 입력을 하지 않은 다음 조치는 **원본 기반 내부 제안**으로만 표시합니다. 브라우저 화면은 조회용입니다.
