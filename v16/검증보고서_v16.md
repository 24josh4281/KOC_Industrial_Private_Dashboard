## 작업현황과 다음 단계

2026 기준 출처별 작업 목록은 222행(관리 Tool 53 + ORS 최신 산업 활동 169)이다. 이는 **고유 신청 222건이 아니다**. 우선순위는 조치 확인 99행, 장기 계류 점검 19행, 일반 확인 104행이다. 30일 이상 변화 확인 118행과 보완 단계 65행은 위 우선순위와 겹칠 수 있어 합산하지 않는다.

각 행은 원본 단계·최근 이력일·보완차수·검토기관 또는 관장기관·업무 담당자·특이사항 근거·다음 조치의 출처를 보여준다. 현재 담당자 입력 다음 조치/의견 내용/사무국 안내는 각각 **0행**이다. 관리 Tool의 기존 자동 다음 조치는 `원본 기반 내부 제안`으로 표시하여 담당자의 확정 입력과 구별한다. 최신 Excel의 `2026 접수·검토·안내` 시트를 편집해 `incoming/workflow/current.xlsx`로 커밋하면 입력을 검증·감사하고 웹·Excel에 반영한다.

## 수치·파일 QA

- v15 기준 관리 Tool 전체 3,419행, 2026 신청일 53행, ORS 수신 원본 5,998행, 산업부문 최신 2026 신규 접수 근거 27행·활동 169행을 다시 대조했다.
- v16 작업 목록 222행에 중복 없는 출처+ID와 상세 URL이 있고, 각 URL의 건별 원본 상세를 찾을 수 있다.
- v16 Excel 77시트·차트 12개. v15의 원본 74시트에 대해 **2,264,583개 셀 값·수식**을 전수 비교해 일치했다.
- 별도 시험 DB에서 Excel 한 행의 담당자·다음 조치·수정일 3개 필드를 가져왔고, 웹 작업 목록에 `담당자 입력` 1행으로 나타났다. 같은 파일 재적용은 변경 0건/중복으로 처리됐다. 입력 열의 수식은 거부됐다. 시험값은 공개판에 포함하지 않았다.
- Python·JavaScript 구문, Excel ZIP 무결성, 차트 수, 원본 상세 연결을 검사했다.

## 현재 특이사항과 운영 순서

1. 관리 Tool 2026 53행의 의견·안내·담당자 입력을 실제 담당자가 확인해 기록한다. 처음에는 **조치 확인**·**보완** 단계부터 검토한다.
2. 검토기관 미기록 32행과 담당자 미기록 197행은 기관명/담당자의 의미를 구분해 확인한다. ORS 관장기관을 검토기관으로 자동 대체하지 않는다.
3. 관리 Tool↔ORS의 사업명·접수일 1:1 일치 23쌍은 대조 후보로만 유지한다. 동일 신청회차임을 확인한 근거가 확보되면 연결 규칙을 추가한다.
4. 컨소시엄 3개 기관의 최신 진행표·현장방문 기록과 공단의 공식 기한 규정/기산일을 받은 뒤 기관별 진행률과 실제 기한 임박·초과를 계산한다. 지금의 30일은 내부 점검 제안이다.
5. 다음 월 ORS ZIP을 `incoming/`에 업로드해 자동 생성·검증·게시 결과를 확인한다. 양식 불일치 또는 날짜 오류면 이전 공개판을 유지한다.

## 공개 범위

저장소와 Pages에는 실제 사업명·검토 메모·원본 Excel/ORS가 공개돼 있다. 이는 이후 사용자의 공개 요청에 따라 운영한 것이며, 제공된 회의자료만으로 공단 또는 계약상 공개 승인을 확인할 수는 없다.
