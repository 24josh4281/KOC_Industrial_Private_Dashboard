월별 ORS ZIP은 저장소의 `incoming/`에 원본 양식 그대로 올립니다. 담당자 의견·사무국 안내·다음 조치는 이 Excel의 `2026 접수·검토·안내` 시트를 편집해 `incoming/workflow/current.xlsx`로 올립니다. 검증을 통과하면 웹과 Excel을 함께 다시 만듭니다.

진행현황의 2026 관련 222행은 출처별 업무 목록(관리 Tool 53행, ORS 활동 169행)이며 고유 신청 222건이 아닙니다. 30일 장기 계류는 내부 확인 기준이고 법정·계약 기한 초과가 아닙니다.
