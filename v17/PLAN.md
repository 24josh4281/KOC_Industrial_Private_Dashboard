# 이너젠 블루 디자인 QA·고도화 계획 (v17)

## P — 확인한 현황

- 통계·진행현황·담당자 작업현황 웹은 같은 CSS를 사용하지만 현재 청록 강조와 둥근 카드가 많다.
- Excel의 통계·진행현황·업무 운영 대시보드는 남색, 다른 파랑, 청록을 섞어 쓴다.
- 기존 이너젠 공개 디자인 기준 `public-release/design.json`과 `design.md`의 `innergen_blue`는 남색 `#0B1739`, 파랑 `#2F62F0`, 보조 `#7B9BF7`, 연한 패널 `#EEF2FF`, 직각 구획, 남색 표 머리를 명시한다. 원본 관리 Tool Excel의 서식은 과거 업무용 혼합 테마이므로 데이터·수식 보존의 참고 자료로 사용한다.
- v16의 77개 시트, 12개 차트, 원본 연결, 업무 입력 기능은 유지한다.

## D — 변경 범위

1. v17을 새 판본으로 만들고 v16을 보존한다.
2. 세 웹 화면과 신청 상세의 공통 색·간격·표·포커스 스타일을 이너젠 블루 규칙으로 정리한다.
3. Excel의 조회용 대시보드 3개와 담당자 업무 표 머리만 같은 색 역할로 조정하고 원본 시트·값·수식은 변경하지 않는다.
4. 월별 ORS/담당자 입력 자동 생성 경로에 v17을 추가한다.

## C — 통과 기준

- v16/v17의 전체 77개 시트 값·수식 동일, 원본 및 지원 시트 구성 동일.
- 차트 12개와 연결 범위 동일, 변경된 시리즈 색이 저장 파일에도 존재.
- 웹 통계·진행현황·작업현황의 브라우저 표시, 검색, 건별 상세, 모바일 폭 확인.
- 월별 갱신 명령과 GitHub Actions 검증·Pages 배포 성공.

## A — 운영 판단

- 색은 상태의 의미를 대신하지 않는다. 30일 내부 점검은 법정 기한 경고로 바꾸지 않는다.
- 공식 기한·컨소시엄별 최신 진행표·동일 신청 회차의 확정 키가 없어 이 부분은 기존의 부분 구현 판정을 유지한다.
