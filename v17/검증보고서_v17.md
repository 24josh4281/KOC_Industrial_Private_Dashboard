# v17 이너젠 디자인·데이터 QA 보고서 · 2026-10-16

## P — 기준과 기존 상태

프로젝트의 `public-release/design.json` 및 `design.md`에서 이미 선택된 `innergen_blue`를 디자인 기준으로 삼았다. 남색 `#0B1739`은 제목·표 머리·핵심 수치, 파랑 `#2F62F0`은 강조, `#7B9BF7`은 보조, `#EEF2FF`는 정보 영역에 적용한다. 모서리는 직각이며 표와 카드의 역할을 일관되게 둔다. v16 웹의 청록 강조·둥근 카드, Excel 차트의 혼합 색은 이 기준과 달랐다.

## D — 변경 사항

- 통계·진행현황·작업현황 웹과 신청 상세에 공통 `brand.css`를 적용했다. 탐색, KPI, 표 머리, 막대, 상태 표시, 버튼, 입력 포커스와 작은 화면 간격을 정리했다.
- Excel의 `통계 대시보드`, `진행현황 대시보드`, `업무 운영 대시보드`의 제목·KPI·안내 영역·차트 색을 맞췄다. 긴 ORS 상태명은 가로 막대로, 일부 화면용 표제는 짧은 말로 바꿨다. `담당자 작업현황`과 `요구사항 점검` 표 머리도 같은 색으로 표시했다.
- 원본 v16과 74개 원본/지원 시트를 보존한 새 `v17` 작업본을 만들었다. 매월 ORS ZIP 및 담당자 입력 자동 생성 경로와 첫 화면·Excel 내려받기 링크를 v17로 연결했다.

Excel은 전체 77개 시트의 값과 수식을 자동 대조했다. 화면 렌더링은 3개 대시보드와 담당자 입력 시트만 발췌한 미리보기로 검토했다. 전체 원본 시트를 렌더링하는 검사는 수행하지 않았으며, Microsoft Excel의 모든 버전에서의 표시 차이는 남는다.

## A — 현재 업무 상태와 다음 단계

작업 목록 222행에서 조치 확인 99행, 장기 계류 점검 19행, 일반 확인 104행이다. 보완 단계 65행, 내부 30일 점검 118행은 앞의 우선순위와 겹칠 수 있다. 담당자 미기록 197행이며, 담당자 입력 의견·안내·다음 조치는 현재 각각 0행이다. 우선 `2026 접수·검토·안내` 시트에서 조치 확인·보완 건의 담당자, 의견, 사무국 안내, 다음 조치, 수정일을 확인해 기입한다.

회의 요구의 구현·부분 구현 판정은 [v16 회의 요구 검증보고서](../v16/검증보고서_v16.md)와 같다. 공식 기한·기산일, 컨소시엄별 최신 자료, 관리 Tool↔ORS 동일 신청회차 키가 확보되기 전에는 법정 초과·기관별 확정 진행률·고유 신청 수를 단정하지 않는다. 공개 저장소에는 실제 사업명·검토 메모·원본 파일이 들어 있으므로 향후 수기 입력도 공개 가능한 내용만 기록한다.
