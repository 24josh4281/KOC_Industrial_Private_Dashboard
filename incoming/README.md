# 월별 ORS ZIP 업로드

받은 ORS ZIP을 이 `incoming` 폴더에 원본 이름 그대로 업로드하고 GitHub에서 **Commit changes**를 누르세요. 월별로 나누고 싶으면 `incoming/YYYY-MM/` 하위 폴더를 사용해도 됩니다.

커밋하면 GitHub Actions가 원본 ZIP의 중복·양식·기준일을 검사합니다. 통과 시 통계 대시보드, 진행현황, 건별 상세, Excel 작업본을 같은 DB 자료로 다시 만들고 공개 페이지에 배포합니다. 배포가 완료되면 이미 열린 페이지는 30초 간격으로 새 판본을 확인합니다. 검증 보류나 작업 실패 시 기존 공개 판본이 유지되며 사유는 Actions 로그에 남습니다.

ZIP 안의 XLS는 지금까지 받은 ORS 양식을 기준으로 검사하며, 원본 ZIP은 수정하지 않습니다. 이전 경로 `v13/incoming/`도 계속 지원합니다.
