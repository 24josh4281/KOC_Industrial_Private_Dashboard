# 산업부문 외부사업 통합관리 v13 검증보고서

기준: 2026-10-15 회의록·제품 기술서, 관리 Tool 2종(2026-10-13), ORS ZIP 7월 31일·9월 21일. 본 보고서의 “원장행”은 사업 또는 신청 회차의 확정 건수가 아니다.

## P — 문제와 검증 범위

v12는 회의용 집계에 필요한 열을 골라 3,419개 행을 보여주었으므로, 원래 두 관리 Tool의 모든 데이터가 새 Excel·웹·DB에 있다는 요구를 충족하지 못했다. 특히 보조 통계·ORS 복사본·비공개 자료·공휴일·원본 수식 및 수기 비고가 전체 범위로 포함되지 않았고, 2026 접수·의견·사무국 안내가 별도 실무 기록으로 관리되지 않았다. 매월 ZIP을 덮어쓰기 없이 추가하고 반복 입력·범위 변경을 감지하는 절차도 필요했다.

원본 4개 파일의 SHA-256이 보관본과 일치했다. SQLite `integrity_check`와 외래키 검사를 통과했다. 시험 DB에서 새 ORS ZIP 1개를 두 번 반영했을 때 원본 출현은 한 번만 늘었고, 기존 관리 원장 3,419행·ORS 고유 업무행 5,789행은 변하지 않았다. 2026 실무 입력도 동일 파일 재반영이 차단되고 변경 필드 3개의 이전값·새값 이력만 남았다. 실제 Edge에서는 2026 목록·CSV, 관리 36개 시트/ORS 20개 파일의 원본 조회, 모바일 폭, 브라우저 오류 없음, 외부 요청 없음이 확인됐다.

월별 갱신 전체 경로는 별도 **시험 DB와 시험 ZIP**으로 재검증했다. 새 ZIP 1개를 더한 판본에서 ORS 원본은 21개 시트·저장 셀 313,965개가 되었고, 일반 값 241,695개와 특수셀 총 112,766개를 원본 주소별로 대조해 누락·추가·불일치 0건이었다. 기존 관리 원본 값 450,690개와 수식 81,374개, 2026 업무 53행, ORS 이력 후보 149행, 차트 4개도 유지됐다. 시험 자료는 배포 Git 판본에 넣지 않았다. 대용량 Excel 내보내기 오류와 ORS 시트 순서 이동을 발견해, 검증된 기준 Excel에 새 ORS 시트를 순서대로 추가하는 방식으로 수정했다.

## A — 운영 원칙과 남은 위험

`2026 접수·검토·안내`의 “미기록”은 미실시 확정이 아니다. 실무자가 입력하고 DB로 가져온 뒤 새 판본을 만들어야 웹과 Excel이 함께 바뀐다. 웹 브라우저의 임시저장만으로 공유 DB를 수정하지 않는다. ORS 2026 이력 149행에는 갱신·보완·처리가 포함되어 신규 신청 건수로 사용할 수 없다. 법정·계약 기한 초과는 규정·기산일이 확보되기 전까지 산출하지 않는다. 신규 관리 Excel이 들어오면 현재 기준판의 행 연결키가 바뀔 수 있으므로 별도 대조가 필요하다. 원본의 서식·개체·셀 주석 등은 새 Excel에 재구성하지 않았으며, 동봉 원본 파일에서 확인한다.

공개 저장소로 전환하면 실제 사업명·담당자·검토 메모·원본 파일과 이전 커밋까지 누구나 내려받을 수 있다. 공개 권한과 자료 반출 적정성은 운영 주체가 확인해야 한다.
