# 외부사업 대시보드 v19 · 공개 통계판

[웹 대시보드](index.html)는 v19 로컬 작업본의 **집계만** 공개하는 읽기 전용 화면입니다. 연도·처리 단계·신청 업무·국내외 및 2026년 월별 추이를 살필 수 있습니다. 각 막대는 실제 건수에 비례합니다.

신청기관, 사업명, 담당자, 의견, 안내, 연락처, 원본 Excel, 원본 JSON, 로컬 SQLite DB는 이 폴더에 넣지 않습니다. 신청별 상세 조회와 등록·수정·Excel 왕복은 v19 로컬 작업본에서만 실행합니다. GitHub Pages는 로컬 Python 서버와 데이터베이스를 실행하지 않습니다. 따라서 이 공개 화면을 실시간 공동편집 화면으로 안내하지 마세요.

`summary.json`은 2026-10-16의 관리 도구 수신본에서 만든 고정 집계입니다. 월별 ORS ZIP이 `incoming/`에 추가되더라도 이 v19 집계는 자동 갱신되지 않습니다. 새 공개본은 원본 검증 후 다시 만들어 배포해야 합니다.

배포 전 확인: `python build_public.py <로컬 v19/data/applications.json>`으로 다시 만들고, `python verify_public.py`를 실행합니다. 원본은 별도 로컬 폴더에 둡니다.
